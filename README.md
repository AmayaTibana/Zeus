Handmade code. Random problems. Zero master plan.

Welcome to my little coding playground.

This repository is a collection of individual coding problems, experiments, practice exercises, and random ideas I work on while learning to program.

Some solutions might be elegant. Others might make me question my life choices. Both are part of the learning process.

☕ Handcrafted code, one problem at a time.

🧠 The Idea

The purpose of this repository is simple: practice, experiment, and learn by doing.

I’m using it to test my understanding of individual programming concepts, try different solutions, and get more comfortable writing code.

This isn’t a production codebase, a finished product, or an attempt to build a perfectly organized portfolio.

It’s a digital workbench where I can experiment freely without pretending everything needs to become a serious project.

The rules are simple:

* Learn something.
* Write some code.
* Break something.
* Figure out why it broke.
* Move on to the next problem.

Repeat as necessary.

⸻
